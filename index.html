Why partitioning helps Quick Sort


Partitioning does not fully sort the list. It only separates the values into two groups: values smaller than the pivot move towards the left, and values larger than the pivot move towards the right.




Left partition
quickSort(lst, start, index - 1)


Returned index
index = left


Right partition
quickSort(lst, index, end)




In this version, return left gives the first index of the right partition after the pointers cross. It is not necessarily the final position of the pivot value.
